Whisker Bloopers Studio

The publishing tool behind the Whisker Bloopers YouTube channel

What it is

Whisker Bloopers Studio is a private tool used only by the team that runs the Whisker Bloopers YouTube channel, a channel of funny cat fails, bloopers and chaos. It prepares the channel's own compilation videos, made from licensed clips, and publishes them to that one channel.

What it does with YouTube

With the channel owner's permission, granted through Google sign-in, the tool:

  • uploads the channel's videos, with their titles, descriptions, tags and thumbnails;
  • sets each video's visibility and publish time;
  • reads the channel's own videos to confirm an upload finished processing.

It acts only on the Whisker Bloopers channel. It is not offered to the public and does not access anyone else's account.

Privacy

How the tool handles data is described in the Privacy Policy. The tool uses YouTube API Services; by using it you agree to the YouTube Terms of Service.
