Privacy Policy

Whisker Bloopers Studio · Last updated: October 25, 2026

1. Who we are

Whisker Bloopers Studio ("the tool", "we") is a private publishing tool used only by the team that runs the Whisker Bloopers YouTube channel. It is not offered to the public. Contact: lacurom13@gmail.com.

2. YouTube API Services

The tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What data the tool accesses

When the channel owner signs in with Google and grants permission, the tool receives an access token for the YouTube scopes requested on the consent screen. With it, the tool can:

  • upload videos to the owner's channel and set their title, description, tags, thumbnail, visibility and publish time;
  • read the channel's basic information (channel name and ID) and its own videos' status, to confirm that an upload finished processing.

The tool does not read comments, messages, subscribers' personal information, payment details or any other account's data.

4. How the data is used

The data is used only to publish and manage the Whisker Bloopers channel's own videos. It is not used for advertising, profiling, or any purpose unrelated to publishing those videos.

5. Storage and security

The OAuth token is kept in private, access-controlled storage used only by the tool, and is sent only to Google's servers over encrypted connections. Video files are deleted from the tool's storage after they are uploaded. Records of what was uploaded (video ID, title, publish time) are kept to run the channel.

6. Sharing

We do not sell, rent or share data obtained through YouTube API Services with third parties. Data is disclosed only when the law requires it.

7. Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. Retention and deletion

The token is kept for as long as the tool publishes for the channel. The channel owner can revoke the tool's access at any time at myaccount.google.com/permissions; the stored token then stops working and is deleted. To ask for deletion of any other stored data, email lacurom13@gmail.com; we act on requests within 30 days.

9. Children

The tool is not directed to children and is used only by the channel's team.

10. Changes

If this policy changes, the new version is posted on this page with a new "Last updated" date.
